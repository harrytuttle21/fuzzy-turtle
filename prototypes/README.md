# prototypes

Throw-away experiments to de-risk the project. / *Essais jetables pour lever les risques techniques.*

- `maschine-hid/` — Maschine MK3 pads, LEDs and screens over HID (macOS + Pi)
- `qt-juce/` — play an audio file from a Qt window with headless JUCE
- `pi-shaders/` — 2–3 GLSL effects at 720p on Raspberry Pi 5
